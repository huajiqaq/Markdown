# 增量解析：检查点、持久化索引与失效规则

## 算法与边界

MarkdownParser 的完整解析、编辑和流式追加共享一个引擎；第一次编辑不再复制原文并启动第二次全量解析。编辑和流式追加使用同一条更新路径：规范化输入 → 持久化行树编辑 → 查找旧检查点 → 重解析影响区 → 接回完整后缀 → 执行失效的后处理 → 发布新根节点。

解析器、Compose 和 HTML 共用 parser 模块的不可变 `MarkdownParserConfig`。配置封存 Emoji 映射，Flavour 封存 Starter 与处理器列表；每个 Flavour 惰性持有自己的编译计划，每个解析会话只建立一次执行管线。通过 `copy/with` 派生新设置后创建独立会话，不在会话中修改注册表，也不维护全局 Flavour 缓存。

`SourceText` 使用不可变 AVL 行树。每个叶子保存一行及其哈希，内部节点汇总字符数、行数、滚动哈希和高度。短行直接保存 String；超过 1,024 字符的行同时建立持久化文本片段树，编辑共享未变片段，只复制大小有界的叶子和树路径。初始行保留已存在的 String，完整解析不为读取该行再次展平；编辑后的分块行在解析器实际请求行文本时才物化。片段哈希按连接关系组合，完整重建与任意编辑得到相同范围哈希。`content` / `currentText()` 明确请求完整 String 时才进行 O(N) 展平；普通更新不会调用它们。已有 SourceText 快照保持不变。

`BlockParser` 在块延续与关闭检查后、开始当前行的新块前记录检查点。只有开放块栈仅剩 Document 时才允许记录。每个检查点携带已经完成的根子节点数量；因此列表或引用内部导出到根节点的定义仍属于整个容器的解析区间，不会被误认成可独立解析的根块。

如果前一个块是通过观察检查点所在行才关闭的，该检查点标为依赖当前行。修改该行时重解析起点回退到前一个区间。关闭围栏、数学定界符和空行都不通过字符串猜测边界。

区间保存在另一棵持久化 AVL 树 `BlockIndex` 中，内部节点汇总源行数、输出节点数、标题数和依赖标记。新文档的 children 是这棵树的 List 视图，发布不复制稳定前缀。随机访问为 O(log B)，顺序迭代为 O(B)。为复用当前解析树，复用节点的 parent 指向当前版本根节点，节点身份保持不变；AST 本身不是不可变历史快照。

## 后缀复用的充分条件

只在以下条件全部满足时停止重解析：

1. 候选位置是旧解析器记录过的根检查点，同时是完整缓存区间的开始。
2. 候选位于编辑后完整未变化的源行中；单次编辑的 offset、删除长度和插入长度证明整个后缀精确相等。
3. 新解析器也在该位置自然回到根状态。
4. 没有跨该边界的后处理依赖，也没有需要刷新全文的语义失效。

停止解析与拼接使用同一份区间计划。后缀整体复用，不再逐个验证和过滤节点。contentHash 仍用于渲染缓存，但既不负责证明解析上下文相同，也不作为正确性的哈希碰撞假设。

旧检查点先定位一次，再顺序遍历。受影响的源行也顺序遍历，并建立本次解析区间的临时哈希前缀；块哈希查询 O(1)，不会对影响区内每一行重复查询行树。

## 语义与后处理失效

- 普通局部编辑只运行影响区的内置局部后处理，已完成的前缀/后缀不会重复追加属性、过滤 HTML 或转换节点。
- 独立属性段落与它依赖的前块合并成一个缓存区间。新编辑把普通段落变成属性段落时，自动扩大到前一区间重新解析。
- 参考文献定义与其连续段落按消费关系合并，避免被删除的段落在后续编辑中丢失。
- 标题在局部后处理前保存原始 slug / 自定义 ID 输入。标题发生变化时，只遍历索引中含标题的分支重建全局 ID，避免使用已经被属性或缩写修改过的输出重新推导原始输入。
- 实际定义变动会全量重建引用语义，包含被遮蔽的重复定义、列表/引用内部定义及参考文献。普通 `]:` 文本不会触发定义失效。
- 存在脚注定义时，影响区含 `[^` 标记会保守刷新全文，以保持已经物化的编号一致；这也可能覆盖代码中的同形文本。
- 引用定义未变化时，共享定义上下文；不在每次普通追加复制定义表。定义发生变化则创建全新上下文。
- 自定义全文 PostProcessor 每次更新走完整解析与完整后处理，保证非幂等或跨文档插件正确；单块转换使用独立的 BlockPostProcessor 接口。
- Lint 是全局处理，开启后每次发布重算诊断。

旧 DirtyRegionTracker / NodeReuser 公共工具保留兼容入口并弃用：前者在没有检查点时返回保守全量区间，后者验证完整候选后缀后才允许平移，失败不丢弃部分节点。新引擎不使用这两个工具。

全量解析仍运行一次完整后处理管线。分组在原始语法上完成，内置转换保持组顺序，再把处理结果分配回缓存区间。

流式 display repair 只应用于可能继续变化的尾部区间；依赖最后一条可追加空行的区间与前一区间合并为原子的 display 缓存区间，编辑不能只复用半个修复尾部。endStream 重新解析该尾部以移除修复，不依赖全文重解析掩盖中间态。取消会提交合并缓冲后保留可显示快照；后续非流式编辑会先移除 display repair。CRLF 跨 chunk 只规范化成一个换行，流中穿插编辑也保留原始 CRLF 配对状态。

## 复杂度

设 N 为全文字符数、L 为行数、B 为缓存区间数、I 为插入字符数、K 为两条编辑边界行的文本片段数量、R 为新重解析输入/节点及被替换旧区间节点的总规模、P(R, C) 为语法/局部后处理本身的成本（C 包括引用字典等上下文）、S 为需要移动绝对坐标的已物化后缀节点数、G 为失效的全局处理成本。

一次更新的框架成本：

```text
O(log L + log B + log(K + 1) + I + R + S + G)
```

另加 P(R, C)。固定大小尾部的普通追加（无全局失效）为 O(log N)，不再包含全文复制、全文行索引重建或稳定块列表复制。没有坐标变化的中间等长替换也不遍历后缀。只有字符偏移变化、且后缀没有绝对 SourceRange 时，同样跳过坐标遍历。

坐标摘要在区间建索引时捕获。`IncrementalCostBoundaryContractTest` 验证解析期已登记的绝对坐标及已物化后代随连续编辑平移；`IncrementalPositionedEditScalingTest` 检查等长更新不随稳定后缀分配。已发布节点拒绝调用方修改坐标和语义字段，避免建索引后外部添加坐标使摘要失效。插件应在构建阶段完成转换，修改源码通过解析器编辑接口提交。

旧实现每次提交追加都会展平全文、重建全部索引并遍历稳定块，维护成本至少 Ω(N+B)。新实现消除了这项线性基数成本。一次完整 String 输出仍为 O(N)；渲染/导出全文和全局 Lint 也不能算作恒定时间。

未闭合大块、修改闭合标记、定义变动或自定义全局插件可能影响全文。根级、零缩进的普通开放代码围栏另有追加快路径，见下文；其他容器仍使用检查点重解析。算法不承诺所有编辑均为亚线性，也不承诺语法解析器所有规则具有线性最坏复杂度。引入持久化索引会增加初次全量解析的固定开销，应同时查看全量与增量门禁。

## 有界文本片段、开放围栏与失败扫描

流式合并仍保持 16 字符阈值和换行提交。每个接收到的 chunk 更新源码时，长单行的稳定片段不再反复复制、重新哈希；缓冲接收与真正提交解析仍是两个不同的测量对象。

内置方言的根级普通围栏在开启行已完成、没有缩进、没有全局 Lint 或未知处理器时，可以继续其已确认的开放状态。下一次追加只检查旧末行和新增行是否出现关闭围栏，不重建此前正文与块节点。检测到关闭、未完成开启行、嵌套／缩进围栏、图表转换或语义失效时，使用原检查点路径。关闭判定沿用原语法，不能仅凭内容哈希复用。检查成本包含候选关闭行的实际扫描字符数；极长开启围栏后逐字符补齐关闭 run 的情况，仍可能重复扫描该候选末行，不宣称所有围栏输入的累计工作都线性。

快路径的代码正文绑定本次已提交的不可变 SourceText 快照。`FencedCodeBlock.literal: String` 第一次读取生成完整 String，后续读取缓存；构建阶段赋值会清除延迟来源，发布后调用方不可再赋值。未提交缓冲不会进入该正文，`endStream` 仍移除显示修复，取消后仍可继续编辑。每次提交都读取不断增长的完整正文时，输出本身仍可能累计平方复制；此成本没有算作恒定时间解析，也没有通过减少已提交内容绕开。

开放状态校验源码／文档／区间／节点身份。发布封存阻止外部原位修改围栏字段及属性集合，不再维护一份用于兼容外部写入的元数据副本。只有新解析出的流式末区间可以建立续写状态，后续快速提交不在每次追加重读开启行。

行内强调按分隔符类别、开闭属性和长度模 3 维护失败搜索下界；反引号记录完整失败扫描后各长度 run 的最后位置，directive 和 spoiler 缓存终止符／失败区间。URL 尾部裁剪仅移动索引并最后截取一次。相邻纯文本一次合并，避免重复拼接前缀。内部可选工作量计数器用于确定性增长测试，不以机器相关耗时断言替代算法验证。

同一次行内解析中的脚注编号只统计一次已有编号，并考虑构建期多个标签引用同一定义节点的情况。跨行内调用重新统计定义状态，因此不宣称跨段落脚注编号完全线性；延迟物化仅由内部编号入口更新 index，不对外解封定义节点。

无需显示修复的行内内容继续保持惰性；若尾段包含有定义的脚注引用，仍保持原来在 append 时物化和编号的时机。确实需要修复或脚注编号时共享定义上下文，不复制三张定义表。表格保留表头和已完成行原有的显示修复行为，只去除安全可省的物化与列表快照。

`SourceTextChunkedLineTest` 和 `LazyFencedCodeLiteralTest` 核对源码历史、分块边界、EOF 空行和公开正文读写；`RootFenceAppendContractTest` 与 `StreamingTailWorkContractTest` 覆盖快路径边界和修复语义。`GrowingBlockAllocationScalingTest` 将连续追加从 512 次扩大到 4,096 次，要求长单行源码维护及不读取完整正文的开放围栏发布，累计分配增长小于 14 倍。该约束不包括主动展平每个完整输出的成本。

## 发布与增量编译

Flavour 的构建及文档后处理在提交前执行。`BlockPostProcessor.processBlock` 接收单个可变块，返回原块、替换块或 null；引擎自动维护结构及坐标继承，并仅在新解析区间执行局部转换。它不能修改已发布前缀或全局定义，跨块语义使用普通 `PostProcessor`，引擎按全局依赖重建。调用方不管理版本、脏区或提交事务。

引擎与独立完整解析对照共用块转换执行器。输入脱离父节点，在撤销文档写入权限后物化外部惰性回调，再授权当前子树执行转换；输出先拒绝捕获的已发布前缀，再物化、检查定义与继承元数据。发布流程逐块封存，阻止后续回调通过捕获引用修改先前输出；独立完整解析对照继续保留构建态，允许后续全文处理与惰性编号。

扩展可以把绝对行号或偏移写进显示内容。存在自定义 Starter 或块转换器时，若前部增删导致稳定后缀位置变化，引擎自动重新执行扩展，避免只平移坐标却保留旧语义。尾部追加和中段等长更新仍可局部处理，不要求调用方声明位置依赖。外部延迟回调在发布前完成并检查是否遗留新的回调，只有内置行内解析保持提交后的惰性物化。

每次真正提交生成 `DocumentPublication`，包含私有 lineage、基版本、新版本及根 children 的 splice（含不可渲染节点）。未变根块保留 `persistentId`，身份独立于绝对行号和偏移。发布只封存变化节点与元数据；标量写入、子树操作、集合别名和延迟回调都受权限边界约束。文档是当前只读视图，旧视图会过期；可持有的历史渲染结果由独立不可变 IR 保存，不宣称 AST 节点是历史快照。

空容器的子列表、只读包装、定义字典 backing 与集合视图按需创建；临时文档不提前创建会被继承替换的权限对象或空诊断。内部元数据遍历直接读取已物化存储，发布封存直接遍历变化区域，避免公开持久化列表的协程迭代器。单根块身份匹配不构建字典与装箱 ID 集合。属性及集合只复用库自己创建的不可变快照；可变 backing 上的只读视图仍需复制，公开视图仍保留原有可见性和写入保护。

渲染会话按版本验证 splice，以持久化 AVL 更新输出槽位并复用稳定块 IR。组合阶段直接读取版本，不计算全文语义哈希；暖编译只遍历插入区间。跳版、换 lineage、编译环境变化或全局依赖失效时完整重建，过期 AST 视图直接拒绝。冷编译保留为独立语义对照。标题／定义变化及其他真实全局转换仍有相应全文成本，不将局部更新结论推广到所有输入。

缓存依赖按实际作用划分：输入转换链以转换器实例、顺序和流式声明识别，变化后刷新解析与源码映射；仅替换指令渲染器时复用该输入链。IR 编译环境只保留标题编号与软换行策略，流式结束或渲染插件替换不会使稳定 IR 失效；布局直接接收当前指令注册表。Compose 按插件引用顺序检测替换，不依赖插件自定义的 `equals`。

共享块布局缓存同时核对不可变 IR 引用，覆盖目录条目、标题编号及祖先容器的全文派生语义；稳定 IR 继续命中，冷编译的新 IR 保守重新布局，不扫描内容计算深层哈希。行内断行缓存使用最终行内模型的版本，包含布局阶段添加的标题编号。

`RenderCompileSessionTest` 检查真实访问节点数、稳定 IR 引用、冷编译等价及槽位随机替换；`RenderCompileAllocationScalingTest` 检查 100 / 1,000 / 10,000 段稳定前缀的编译分配增长。真实规模基准分别报告 cold / incremental 编译，详见 [BENCHMARKS.md](../markdown-benchmark/BENCHMARKS.md)。

规模基准在计时外初始化解析器，测量完整 append / replace 调用，报告中位数、p95 和线程分配量。它不把 currentText() 展平或 AST 全量遍历混入局部更新测量；这些调用有各自明确的输出成本。单次测量不能推广成所有 Markdown 文档的固定提速倍数。

## 全量路径与流式提交边界

围栏内容只在本次块解析完成时拼接一次；解析区间在 EOF 或复用边界处也会完成尚未关闭的块，
因此每个已提交的流式快照仍包含当前收到的代码正文。不会为了该优化跨多次提交累积代码。
`LlmStreaming` 的 16 字符合并阈值、换行提交、结束/取消刷新尾部的策略保持不变。

连续链接/缩写定义在原字符串上推进偏移和行号，只在返回剩余正文时取一次子串，避免逐定义复制后缀和重扫前缀。
表格探测先验证当前分隔行，再读取段落表头，避免对普通多行段落逐行复制不断增长的前缀。
这些改动消除了相应输入族的二次方复制成本；不将任意扩展语法、嵌套或自定义处理器都声明为线性复杂度。
持久化索引、检查点和全局依赖失效规则保持不变。

定义检测、绝对坐标检测和标题 ID 的结构遍历直接读取已物化的子节点，不为每层容器创建列表副本，
也不提前触发行内解析。会增删或替换子节点的后处理仍保留快照。处理前只保存原始语义元数据，
输出节点列表在后处理完成后捕获；普通正文更新不构建仅供标题 ID 重排使用的临时索引。
只读检测的时间复杂度仍为 O(V + E)（V 为已物化节点数，E 为父子关系数），减少的是列表复制和分配常数，
不会改变流式提交边界或全局失效规则。

`FullParsingAllocationScalingTest` 检查长块与连续定义的分配增长，`fullParsingBenchmark` 另测真实物化行内 AST 的成本。
既有 `streamingAppendBatch` 基准继续使用 16 字符合并阈值，完整增量分配与解析范围回归同时执行。
